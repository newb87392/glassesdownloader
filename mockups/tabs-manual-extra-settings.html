What moves where: the action row, device picker, destination radios/warning and private-gallery button stay above the tabs because the Bluetooth flow needs them too. Manual = the existing Wi-Fi fallback (SSID + “Download using current Wi-Fi”) plus advanced connection (scan filter, alternate P2P mode). Extra Settings = new video-length control (BLE cmd 2, seconds as 2-byte big-endian), the existing 2K / 16:9 experimental button. Tab state persists while the log keeps autoscrolling at the top.
